Design system

Components and intent

YouTube’s visual language — Roboto, near-black ink, chip greys, rounded 16:9 thumbnails — held to one editorial rule: the page should read like a briefing, and red means exactly one thing. Every example below is rendered from live data.

Colour

Written as intent, not hex. Neutrals do almost all the work.

Outperformance

YouTube Red. Appears only where a creative beat its own channel’s median by 1.5x or more. Not on the logo, buttons, chips or headers — if red is on screen, something worked.

Ink / structure

YouTube near-black. Headings, active navigation, the 1.0x baseline marker, and bars that are above baseline but not outperforming.

Secondary text

Metadata, captions, audience themes, the flagged footnote.

Tertiary / below baseline

Dimension captions and below-baseline bars. Underperformance gets no colour of its own — absence of red is the signal, without passing judgment.

Chip grey

Neutral containers: attribute chips, filters, the video details panel.

Callout tint

Sets the shift callout and status banners apart without borders.

Link

YouTube link blue, for navigation text only.

Type

One family (Roboto), two voices. The insight is set large and regular so it reads as a sentence; data is small, quiet and tabular so columns of indices line up.

Insight voice — 26/36 regular. “Three of the last five are UGC.”

Data voice — 12/16, tabular figures: 0.04x · 1.8x · 22.6x · 1,891,981 views

Performance indicator

The index against the channel’s own median for the same format, on a log scale with the 1.0x baseline marked. The line is the concept: you’re seeing relative performance, not absolute views. Dashed fill = under 7 days old.
